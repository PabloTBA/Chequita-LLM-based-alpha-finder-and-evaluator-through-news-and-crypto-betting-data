## ── Run full stack: Crucix sidecar + Chequita backend ───────────────────────

# TERMINAL 1 — start Crucix intelligence sidecar (Node 22+ required)
#   First time only: copy the env template and fill in your keys.
#   Minimum useful keys: FRED_API_KEY, FIRMS_MAP_KEY, EIA_API_KEY (all free)
cd Crucix-master
cp .env.example .env
npm install
node --trace-warnings server.mjs
#   Crucix will be running at http://localhost:3117
#   First sweep takes ~30-60s; after that it auto-refreshes every 15 minutes.

# TERMINAL 2 — run Chequita after Crucix has completed its first sweep
#   (wait ~60s after starting Crucix before running the pipeline)
cd ..
python pipeline_orchestrator.py 2026-04-04

## ── Optional: FastAPI streaming server (frontend-facing) ────────────────────
# TERMINAL 3 — FastAPI server that wraps the pipeline with SSE log streaming
uvicorn api_server:app --host 0.0.0.0 --port 8000 --reload
